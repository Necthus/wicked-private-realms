# 五人实验包：待多人验收

该包只用于隔离测试，当前正式版仍是 v0.2.5（四人）。客户端和服务端必须配套；不支持将普通四人客户端接入五人会话。

当前已验证一个真实游戏客户端占用第五模拟槽位的创建、输入移动、场景启动、退出保存，以及第五人字段的快照/校验往返。还没有五台真实客户端同时游玩的结果。

服务端：使用本实验 Server ZIP，先修改 server-config.json 的加入密码，保持 max_players=5、experimental_first_slot=0；数据库必须使用新建测试国度或生产数据库副本。按服务端教程启动并开放配置的 TLS 端口。

客户端：游戏必须为匹配的 v29466。独立保存原 wicked-client 目录，再把实验包的 wicked-client 放在游戏 EXE 旁。运行 Start-Five-Player.cmd，它仅为本次启动启用实验变量。输入测试服务器地址、加入密码及各自不同的 Steam ID。

普通入口不会自动开启实验扩展；测试时统一使用专用入口。五人都需要相同实验包。先各自进入、移动，确认第五人能控制角色并被其他人看到；随后测试保存返回菜单、重进、地图切换、聊天、战斗与过场。

反馈时提供 native-game.log 与 native-adapter.jsonl 中的错误；不要发送密码、信任记录、私钥或个人完整存档。发生异常先保留日志，停止实验。恢复原客户端即可回到正式四人版本；实验数据不直接覆盖生产服务器。
